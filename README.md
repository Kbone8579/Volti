# Volti — 손 대지 않고 넘기는 악보

> 이름은 악보 페이지 끝에 적는 **V.S. (volti subito, "빨리 넘기시오")** 에서 왔어요.

악보를 보면서 **얼굴 제스처(고개 · 입 · 윙크 · 시선 · 직접 녹화한 동작)로 페이지를 넘기는** 웹앱입니다.
카메라 영상은 브라우저 안에서만 처리되고 서버로 전송되지 않습니다.
Google 계정으로 로그인하면 악보와 설정이 계정에 저장돼서, 브라우저 데이터를 지우거나 기기를 바꿔도 그대로 이어서 쓸 수 있어요.

## 실행

```bash
npm install        # 설치하면서 MediaPipe·pdf.js 리소스를 public/ 으로 복사
npm run dev        # http://localhost:5173  (노트북 웹캠으로 바로 테스트, 서버도 같이 켜짐)
```

`npm run dev` 는 화면과 함께 **서버(`server/`)도 내 컴퓨터에서 같이 실행**해요. DB와 파일 저장소는 `.wrangler/` 폴더에 흉내 내요.
Google 설정 없이도 **설정 › 계정 › 「테스트 계정으로 로그인」**으로 동기화를 시험해 볼 수 있어요
(`.dev.vars` 의 `DEV_LOGIN=1` 덕분 · localhost 에서만 · 배포된 사이트에는 없음).
일반 창과 시크릿 창에서 같은 이메일로 로그인하면 두 기기처럼 맞춰지는 걸 볼 수 있어요.

### 태블릿에서 쓰기

웹앱이라 태블릿 브라우저(아이패드 Safari, 갤럭시탭 Chrome)에서 주소만 열면 돼요. 단, 카메라는 **HTTPS 또는 localhost**에서만 켜집니다.
로그인하지 않으면 라이브러리 · 설정은 **기기(브라우저)마다 따로** 저장돼요. 로그인하면 계정으로 맞춰져요 (아래 「계정 · 동기화」).
아이패드는 Safari 공유 → 「홈 화면에 추가」로 전체화면처럼 쓸 수 있어요. 홈 화면 앱에서도 Google 로그인이 돼요.

- **같은 와이파이에서 바로**: `npm run dev:https` 실행 → 태블릿에서 `https://<노트북 IP>:5173` 접속.
  자체 서명 인증서라 경고가 뜨면 "계속 진행"을 누르세요.
- **배포해서 링크로**: 아래 「Cloudflare 배포」 참고. HTTPS가 자동으로 붙고, 테스터에게 링크만 보내면 됩니다.

## Cloudflare 배포 (화면 + 서버)

설정은 `wrangler.jsonc` 에 들어 있어요. 한 번 배포로 세 가지가 같이 올라가요.

| 무엇 | Cloudflare 제품 | 무료 한도 (2026년 기준) |
|---|---|---|
| 화면 파일 (HTML · JS · 그림) | Workers 정적 파일 | 무료 · 무제한 |
| 서버 코드 (`/api/*` — 로그인 · 동기화) | Workers | 하루 요청 10만 번 |
| 악보 목록 · 설정 · 계정 | D1 (SQLite DB) | 저장 5GB, 하루 읽기 500만 행 · 쓰기 10만 행 |
| 악보 파일 · 썸네일 | R2 (파일 저장소) | 저장 10GB, 내려받기 무료 |

```bash
npx wrangler login     # 처음 한 번: 브라우저에서 Cloudflare 계정 로그인
npm run deploy         # 빌드 + 배포 → https://volti.<계정 서브도메인>.workers.dev
```

- **처음 서버를 올릴 때 한 번**: Cloudflare 대시보드 → **R2** → 「Purchase R2 / R2 사용 시작」으로 R2 를 켜 주세요
  (무료 한도 안에서는 요금이 나오지 않지만, 켤 때 결제 수단 등록을 요구할 수 있어요).
  그다음 `npm run deploy` 하면 DB(`volti`)와 파일 저장소(`volti-files`)를 **자동으로 만들어요** (물어보면 새로 만들기 선택).
- 한 사람이 서버에 올릴 수 있는 악보 용량은 `wrangler.jsonc` 의 `USER_QUOTA_MB`(기본 500MB). 넘치면 그 악보는 기기에만 남고 앱이 알려 줘요.
- **요금이 나가지 않게 서버가 스스로 멈춰요** (`server/freeGuard.ts`).
  - Workers · D1 은 무료 플랜이면 한도를 넘어도 요금 없이 그날만 잠깐 멈춰요.
  - R2 는 한도를 넘으면 카드로 청구되고 Cloudflare 에 「여기서 멈춤」 설정이 없어서, 서버가 직접 셉니다:
    모든 사용자 파일 합 9GB, 한 달 쓰기 45만 번 · 읽기 450만 번(무료 한도의 절반 아래 — 청구 기간이 달력과 어긋나도 안전)에 닿으면
    그달은 올리기를 멈추고, 악보는 기기에만 남아요 (받기 · 지우기는 계속 돼요).
  - 혹시 몰라 Cloudflare 대시보드 › Billing › Billable Usage › **Create budget alert** 로 $1 알림을 걸어 두면 좋아요 (알림만 오고 멈추지는 않아요).
- 도메인 연결: Cloudflare 대시보드 → Workers & Pages → **volti** → Settings → Domains & Routes → 「Add」 → Custom domain
  (예: 계정에 있는 도메인의 하위 주소 `volti.example.com`). 주소를 바꾸면 아래 Google 설정의 「승인된 리디렉션 URI」에도 추가해 주세요.
- 다시 배포할 때도 `npm run deploy` 만 하면 돼요.

### Google 로그인 켜기 (처음 한 번)

로그인 버튼이 보이려면 Google 에서 「OAuth 클라이언트 ID」를 받아 `wrangler.jsonc` 에 넣어야 해요. 클라이언트 ID 는 공개돼도 괜찮은 값이에요.
**클라이언트 보안 비밀(secret)은 쓰지 않아요** — 어디에도 붙여 넣지 마세요.

1. [Google Cloud 콘솔](https://console.cloud.google.com/) → 위쪽 프로젝트 선택 → **새 프로젝트** (이름 예: `Volti`)
2. 왼쪽 메뉴 **Google 인증 플랫폼(Google Auth Platform)** → **시작하기**
   - 앱 이름 `Volti`, 사용자 지원 이메일 = 내 이메일
   - 대상(Audience): **외부(External)**
   - 연락처 이메일 입력 → 동의 → 만들기
3. **브랜딩** 메뉴 → 아래를 채우고 저장 (누구나 로그인하게 「게시」하려면 꼭 필요)
   - 애플리케이션 홈페이지: `https://volti.togetheronlab.workers.dev`
   - 개인정보처리방침 링크: `https://volti.togetheronlab.workers.dev/privacy`
   - 서비스 약관 링크: `https://volti.togetheronlab.workers.dev/terms`
   - 승인된 도메인: `togetheronlab.workers.dev`
   - **앱 로고는 올리지 마세요** — 올리면 Google 심사를 받아야 해요. (로고 · 이름 표시는 나중에 브랜드 인증으로)
   - 두 페이지는 이 프로젝트의 `public/privacy.html` · `public/terms.html` 이고, 배포하면 위 주소로 열려요
4. **대상(Audience)** 메뉴 → 게시 상태 「테스트 중」이면 **앱 게시(Publish app)** → 확인
   (게시하지 않으면 「테스트 사용자」로 등록한 사람만 로그인돼요. 이 앱은 이름 · 이메일 · 프로필 사진만 받아서 앱 심사가 필요 없어요)
5. **클라이언트(Clients)** 메뉴 → **클라이언트 만들기**
   - 애플리케이션 유형: **웹 애플리케이션**, 이름: `Volti web`
   - **승인된 리디렉션 URI** 에 추가:
     - `https://volti.togetheronlab.workers.dev/api/auth/google/callback`
     - (내 컴퓨터에서도 시험하려면) `http://localhost:5173/api/auth/google/callback`
   - 만들기 → 나오는 **클라이언트 ID** (`…apps.googleusercontent.com`) 복사
6. `wrangler.jsonc` 의 `"GOOGLE_CLIENT_ID": ""` 따옴표 안에 붙여 넣고 `npm run deploy`

개인정보처리방침 · 이용약관의 운영자 · 문의 이메일(투게더온랩 · togetheronlab@gmail.com)을 바꾸려면 두 HTML 파일을 고치고 다시 배포하면 돼요.
정식 서비스 전에는 법률 전문가의 검토를 받아 보길 권해요.

내 컴퓨터에서 진짜 Google 로그인을 시험하려면 `.dev.vars` 에 `GOOGLE_CLIENT_ID=…` 한 줄을 넣고 `npm run dev` 를 다시 켜면 돼요.

## 30초 체험 (처음 쓰는 사람용)

처음 열면 **「30초 만에 직접 넘겨 볼까요?」** 안내가 떠요. 샘플 악보로 직접 해 보는 짧은 체험이에요.
고개 말고도 입·윙크·시선, 직접 녹화한 나만의 동작으로도 넘길 수 있다는 것도 함께 알려 줘요.

1. **카메라 켜기** — 얼굴이 보이면 자동으로 다음 단계로
2. **기준 잡기** — 정면을 2.5초 편하게 바라보기
3. **넘겨 보기** — 고개를 돌린 채 잠깐 멈춰서 두 번 넘기기 (두 번째는 정면으로 돌아왔다가 다시 하는 연습)
   - 처음엔 어느 쪽으로 돌려도 받아 주고, 그쪽을 「다음」으로 정해요
   - 안내 카드에 막대가 차오르는 게 보이고, 오른쪽 패널의 해당 부분에 테두리가 표시돼요
   - 안내 카드는 오른쪽 패널의 해당 부분(카메라 · 게이지 · 모드 탭) 바로 옆에 붙어서 화살표로 가리켜요 (폰은 악보 위쪽)
4. **끝** — 알아 두면 좋은 것 안내. **「나만의 동작 만들기」**를 누르면 바로 「내 동작」 탭으로 가서
   눈썹 올리기·볼 부풀리기·입 내밀기 등 원하는 동작을 녹화할 수 있어요

카메라를 못 쓰면 **「카메라 없이 둘러보기」**: 동작이 어떻게 생겼는지 그림으로 보고, 탭·→ 키로 직접 넘겨 봐요.
체험은 고개 모드로 하고, 끝나면 원래 쓰던 모드로 돌아가요. 언제든 ✕ 나 Esc 로 그만둘 수 있고,
**⚙ 설정 → 제스처 → 30초 체험** 또는 **라이브러리 → ▶ 30초 체험**으로 다시 할 수 있어요.

## 사용 순서

1. **라이브러리**(시작 화면)에서 **＋ 악보 추가**로 파일을 고르거나 화면에 끌어다 놓기. 파일이 없으면 "샘플 악보로 해보기".
2. **카메라 켜기**: 오른쪽 **내 화면** 패널에서 내 얼굴과 인식선, 제스처 게이지를 확인해요.
   패널 가장자리의 세로 탭(폰은 아래쪽 탭)을 누르면 접고 펼 수 있어요. 접어도 인식은 계속돼요.
3. **캘리브레이션**: ① 연주 자세로 2.5초 가만히 있기 → ② "다음 페이지"로 쓸 동작을 3초 동안 하고 유지.
   기준값, 방향, 임계값이 자동으로 정해져요.
4. **연주하면서 테스트** → ⚙ 설정 → **테스트 기록**에서 의도하지 않은 넘김을 눌러 "오작동"으로 표시 → **결과 복사**.

## 제스처 종류

| 탭 | 넘기는 방법 | 준비 |
|---|---|---|
| 고개 | 고개를 한쪽으로 돌린 채 잠깐 유지 | 캘리브레이션(선택) |
| 입 | 다문 입을 한쪽으로 밀고 유지 | 캘리브레이션(선택) |
| 윙크 | 한쪽 눈만 감고 유지 | 캘리브레이션(선택) |
| 시선 | 악보 오른쪽 아래 ▶ 를 약 0.9초 바라보기 (다음 페이지만) | **시선 캘리브레이션 필수** — 점 9개 따라보기 |
| 내 동작 | 직접 녹화한 아무 동작 | **동작 녹화 필수** — 평소 연주 5초 + 동작 3초 (+ 이전 동작 3초) |

- **이전 페이지 제스처** 스위치를 켜면 고개·입·윙크는 반대 방향 동작으로, 내 동작은 따로 녹화한 동작으로 이전 페이지로 가요.
- **시선**: 웹캠 시선 추정은 대략적이라 넉넉한 칸으로 판정해요. 자세가 바뀌면 「빠른 보정」(▶ 를 2초 보기)으로 다시 맞춰요.
- **내 동작**: 표정 수치 51개 + 고개 각도를 보고 "평소 자세와 무엇이 달라졌는지" 학습해요.
  평소 자세를 녹화할 때 **실제로 악보를 읽으며 연주**해야, 연주 중 자연스러운 움직임을 넘김으로 착각하지 않아요.
  녹화가 끝나면 어떤 동작으로 인식했는지와 평소 움직임과 잘 구분되는지 알려 줘요.
- **동작 하나만 녹화**: 처음에 「다음」 동작만 녹화했어도, 나중에 **「＋ 이전 동작 녹화」**로 이전 동작만 3초 녹화해서
  추가할 수 있어요 (평소 자세·다음 동작은 그대로, 저장되면 이전 페이지 제스처가 자동으로 켜짐).
  각 동작 옆의 **「다시」**로 그 동작만 다시 녹화할 수도 있어요. 이전 페이지 제스처를 켰는데 이전 동작이 없으면 바로 녹화하라고 알려 줘요.

## 넘기기 전 대기

제스처를 인식한 뒤 **정해 둔 시간만큼 기다렸다가** 넘겨요. 마지막 마디를 연주하면서 미리 동작해 두는 용도예요.

- 카메라 패널의 「넘기기 전 대기」: 바로 · 0.5초 · 1초 · 2초 · 3초 (설정 → 제스처에서 0~5초, 0.25초 단위)
- 기다리는 동안 악보 위에 「▶ 1.4초 뒤 다음 페이지 · 취소」가 떠요.
- 취소: 「취소」 버튼, Esc, 반대 방향 동작. 버튼·키보드·페달·화면 탭으로 넘기면 예약은 지우고 바로 넘어가요.
- 테스트 기록에 대기 중 취소된 넘김은 「대기 중 취소」로 표시돼요.

## 확대 · 축소

- 툴바 **− 100% + 🔓**: 버튼, 배율 메뉴(화면 맞춤 · 너비 맞춤 · 125~300%), 키보드 `+` `-` `0`
- **마우스**: 휠로 확대·축소(커서 위치 기준), 끌어서 이동, 가운데 더블클릭 = 2배 ↔ 화면 맞춤
  (설정에서 휠을 「위아래 이동」으로 바꾸면 Ctrl/⌘+휠로 확대)
- **태블릿·폰**: 두 손가락으로 벌리고 오므리기, 한 손가락으로 끌어서 이동, 가운데 두 번 탭 = 2배 ↔ 화면 맞춤,
  화면 맞춤일 때 좌우로 밀어서 넘기기
- **고정 🔒**: 연주 중 실수로 배율·위치가 바뀌지 않게 휠·핀치·끌기를 막아요.
- 정한 배율은 **악보마다 저장**되고 페이지를 넘겨도 유지돼요. 확대하면 그 크기에 맞춰 PDF를 선명하게 다시 그려요.
- **확대 중 넘김**: 기본은 확대 상태에서도 「다음」·「이전」에 바로 페이지가 넘어가고, 배율과 보던 위치(위아래·좌우)가 그대로 유지돼요.
  (예: 200%로 아래쪽 반을 보고 있었다면 다음 페이지도 아래쪽 반) 새 페이지의 비율이 조금 달라도 보던 부분을 비율로 맞춰 옮겨요.
  설정 → 화면·성능 → 「확대 중엔 아래로 먼저 이동」을 켜면, 페이지가 화면보다 길 때 먼저 한 화면씩 내려간 뒤 넘기고, 새 페이지는 맨 위부터 보여줘요.

## 계정 · 동기화

**설정 › 계정** (또는 라이브러리 위의 「로그인하고 계정에 백업하기」) → **Google 계정으로 로그인**.

- 로그인 안 한 채로 **「＋ 악보 추가」**를 누르거나 파일을 끌어다 놓으면, 먼저 「악보를 계정에 백업할까요?」 창이 떠요.
  「Google 계정으로 로그인」을 고르면 로그인하고 돌아와서 알림의 「악보 추가」로 바로 이어서 넣을 수 있고,
  「로그인 없이 이 기기에만 저장」을 고르면 지금처럼 이 브라우저에만 저장해요 (「다시 묻지 않기」 가능).
- 로그인 안 했는데 내 악보(샘플 제외)가 있으면 라이브러리 위에 「악보 N개가 이 브라우저에만 있어요」 경고 띠가 계속 보여요.
- 로그인 전에 넣은 악보도 로그인하면 자동으로 계정에 올라가요. 순서는 상관없어요.

- 로그인하면 이 기기의 악보가 계정으로 올라가고, 계정에 있는 악보는 이 기기로 내려와요. 이후엔 **자동으로** 맞춰요:
  악보를 넣거나 넘기고 5초 뒤 · 설정을 바꾸고 3초 뒤 · 인터넷이 다시 연결됐을 때 · 앱으로 돌아왔을 때 · 켜 둔 동안 5분마다.
- 상단 바의 **구름 버튼**이 상태를 보여 줘요 (맞춤 · 맞추는 중 · 인터넷 없음 · 문제). 누르면 설정 › 계정.
- **같이 쓰는 것**: 악보 파일 · 제목 · 보던 쪽 · 악보별 배율, 제스처 종류 · 유지·대기 시간 · 이전 페이지 사용 · 보기 방식 · 확대 방식 · 시선 칸, 녹화한 「내 동작」
- **기기마다 따로**: 고개 · 입 · 윙크 기준값(캘리브레이션), 시선 보정, 카메라 해상도 · fps · GPU — 카메라 위치와 기기 성능에 따라 달라서요
- 여러 기기에서 같은 악보를 고치면 **나중에 고친 쪽**으로 맞춰져요. 한 기기에서 지우면 다른 기기에서도 지워져요
  (단, 지운 뒤에 다른 기기에서 그 악보를 더 나중에 고쳤으면 지우지 않고 되살려요).
- 두 기기에 같은 파일(이름 · 크기가 같음)이 따로 있었으면 하나로 합쳐요. 샘플 악보가 두 개로 늘지 않아요.
- 인터넷이 없어도 그대로 쓸 수 있어요 (모든 악보가 기기에도 있음). 연결되면 그동안 바뀐 것을 맞춰요.
- **로그아웃**해도 이 기기에 받아 둔 악보는 남아요. **계정 삭제**는 서버에 있는 악보 · 설정 · 계정을 모두 지워요 (기기 안의 악보는 그대로).
- 서버엔 악보 파일 · 목록 · 설정과 Google 계정의 이름 · 이메일 · 프로필 사진 주소만 저장돼요. 카메라 영상은 여전히 서버로 가지 않아요.

## 라이브러리

- 추가한 악보는 **이 브라우저 안(IndexedDB)** 에 원본 파일째 저장돼요. 로그인하면 계정에도 백업돼요 (위 「계정 · 동기화」).
- 카드에 첫 페이지 썸네일, 쪽수, 마지막으로 연 시각, **어디까지 봤는지**가 표시되고, 다시 열면 보던 쪽부터 이어서 보여줘요.
- 검색(제목·파일 이름), 정렬(최근 연 순 · 추가한 순 · 이름 순), 이름 바꾸기.
- **삭제**: 카드의 🗑 삭제, 또는 「선택」으로 여러 개(모두 선택 가능)를 한 번에. 지운 뒤 몇 초 동안 알림의 **되돌리기**로 복구할 수 있어요.
- 처음 실행하면 테스트용 **샘플 연습곡**(8쪽)이 들어 있어요. 지우면 다시 생기지 않고, 라이브러리가 비었을 때 「샘플 악보 넣기」로 다시 넣을 수 있어요.
- 같은 파일을 다시 추가하면 새로 만들지 않고 기존 악보를 이어서 열어요.
- 주의: 로그인하지 않았다면 브라우저의 "사이트 데이터 삭제"를 하면 함께 지워지고, 다른 기기·다른 브라우저와도 공유되지 않아요.
  로그인해 두면 지워져도 다시 로그인하면 계정에서 다시 받아요.

## 지원 형식

| 형식 | 비고 |
|---|---|
| PDF | 여러 페이지 그대로. 한글 폰트, 스캔본(JBIG2 · JPEG2000) 포함 |
| JPG · PNG · WEBP · GIF · BMP · AVIF | 모든 브라우저 |
| HEIC · TIFF | Safari에서만 열림 (다른 브라우저는 안내 메시지 표시) |

여러 파일을 한꺼번에 고르면 **파일 이름 순서**(숫자 인식: `2` < `10`)로 이어 붙여 한 악보가 됩니다.

## 보기 · 조작

- **한 쪽 / 펼치기 / 자동**: 자동은 화면이 가로로 넓으면 두 페이지를 펼쳐 보여줘요.
- **펼치기 넘김 단위**: 두 장씩(책처럼) 또는 한 장씩(밀어내기). 설정 → 화면·성능에서 바꿀 수 있어요.
- **화면 탭**: 왼쪽 30% 영역은 이전, 오른쪽 30% 영역은 다음.
- **키보드 · 블루투스 페달**: → ↓ PageDown Space는 다음, ← ↑ PageUp은 이전.
  대부분의 페이지 터너 페달이 이 키를 보내기 때문에 그대로 동작해요.

## 제스처 판정 방식

```
신호 - 기준값  ×  방향  =  d
d ≥ 임계값 상태를 [유지 시간] 동안 지속  →  넘김
→ [쿨다운] 동안 무시  →  중립(임계값의 50% 이하)으로 돌아와야 다음 동작을 받음
```

- 고개를 돌린 채로 있어도 한 번만 넘어가요.
- 양쪽 눈을 함께 깜빡이는 동작은 윙크 신호에서 상쇄되어 무시돼요.
- **오작동이 많으면**: 임계값 ↑, 유지 시간 ↑ (400 → 600ms), "앞으로만 넘기기" 켜기.

## 구조

기능(feature) 단위로 정리돼 있어요. **각 폴더·파일이 하는 일, 새 코드를 넣을 곳, 데이터 흐름은 [STRUCTURE.md](STRUCTURE.md)** 에 자세히 있어요.

```
server/               서버 (Cloudflare Worker): 로그인 · 악보/설정 저장 API
src/
  main.tsx            시작점 (전역 스타일 → App)
  app/                앱 껍데기: App.tsx(화면 조립 · 기능 연결), Toolbar, 단축키, 전역 스타일, 흐름 테스트
  features/
    score/            악보 보기 · 넘기기 · 확대 · 넘기기 전 대기
    library/          내 악보 보관함 (IndexedDB)
    camera/           웹캠 + 얼굴 인식 + 카메라 패널
    gestures/         제스처 판정기 · 캘리브레이션 (모든 모드 공통)
    gaze/             시선 모드
    custom-gesture/   내 동작 (녹화해서 학습)
    settings/         설정 값 · 설정 서랍 · 테스트 기록
    tour/             30초 체험
    account/          Google 로그인 · 계정 탭
    sync/             계정과 맞추기 (동기화)
  shared/             공용 훅 · 알림 · 서버 호출
```

각 기능 폴더 = `components/`(화면) · `hooks/`(상태) · `lib/`(순수 로직 + 테스트) · `<기능>.css` · `index.ts`(바깥 공개 목록).
다른 곳에서는 `import { ScoreViewer } from '@/features/score'` 처럼 `@/` 로 가져와요.
